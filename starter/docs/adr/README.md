# Architecture decision records

Each record states one decision: the context, the decision, the alternatives, what it costs, and
how it is checked. Start a new record from [template.md](template.md) with the next number.
Numbers are never reused. An accepted record is not edited; a changed decision gets a new record,
and both records link each other.
